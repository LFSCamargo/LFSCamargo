## About

I’m **Luiz Fernando** — a senior software engineer who turns high-stakes ideas into products people trust on first use.

I have been shipping production software since **2014** (12+ years) across **fintech, AI platforms, blockchain, gaming, and developer tooling**. I work AI-native and spec-driven: unclear product ideas become specs, implementation plans, and reliable shipped outcomes.

Most recent role: **Senior Software Engineer at [Coinbase](https://www.coinbase.com/)**.

- Engineer by profession. A tinkerer at heart — it started in 2012 porting Android ROMs on an old Galaxy
- TypeScript ecosystems (React, React Native, Vue/Nuxt) with backend depth in Node.js, Go, and Rust
- Spec-driven delivery with Claude, Cursor, and Codex from discovery to production
- B.Sc. Computer Science · UNIBTA, São Paulo · 2016–2020
- Open to conversations — [freelance](https://cal.com/thelittleluiz/freelance) or [roles](https://cal.com/thelittleluiz/jobs)

> Good software works. Great software makes you feel something.
